# Безопасность / Security

Нашли уязвимость в CubeXCraft для iPhone? Не публикуйте её в issues. Сообщите приватно: GitHub → вкладка **Security** →
**Report a vulnerability**, или письмом на admin@cubexcraft.site.

Found a vulnerability in CubeXCraft for iPhone? Please report it privately via GitHub → **Security** →
**Report a vulnerability**, or email admin@cubexcraft.site. Do not post it in issues.

Официальные сборки — только с https://www.cubexcraft.site, через установщик CubeXCraft Installer.
Official builds come only from https://www.cubexcraft.site through the CubeXCraft Installer.
